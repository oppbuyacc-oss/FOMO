# Mobile Crypto Terminal V17

Responsive phone-first crypto terminal based on the supplied reference image. The phone home screen includes the brand mark from the reference, balance and deposit row, Monad/Base promo cards, weekly trades, filters, reference-derived visible coin icons and a floating navigation bar. Desktop retains the three-column terminal.

Open `sharky_fomo_mobile_v17.html` in a browser. The chart uses locally generated candle data and orders only update local account state; no exchange orders are sent.
